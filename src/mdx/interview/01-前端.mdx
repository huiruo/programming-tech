- 闭包、作用域、事件循环：直接影响 React stale closure、异步执行顺序和内存泄漏。

但这些考法价值很低：
- 背诵冷门规范名词。
- 默写完整版 Promise。
- 不结合场景地背宏任务、微任务列表。
- 手写已经有成熟标准 API 的工具函数，却不讨论边界。
- 用偏门输出题筛人。

更合理的高级前端面试应该是：
1. 给一段 React 代码，解释为什么状态过期、为什么重复请求。
2. 给一次性能问题，让候选人用 Performance、Network、Heap Snapshot 定位。
3. 设计请求取消、缓存、重试、并发限制和错误隔离。
4. 让候选人审查 AI 生成的代码，找出竞态、泄漏、安全和维护性问题。
5. 讨论方案取舍，而不是只问“是什么”。
